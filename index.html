projetos em que trabalhei

  • Autocontratação de Empréstimo Consignado

    Sistema de autoatendimento para contratação de empréstimo consignado, desenvolvido com Java e React. Atuação no desenvolvimento e evolução de funcionalidades, integração com a API Direct Data para consulta e validação de dados cadastrais, integração entre serviços e manutenção da plataforma.

  • Suporte ao Consumidor via WhatsApp

    Plataforma de atendimento integrada à API do WhatsApp, desenvolvida com Node.js e Java. Atuação na evolução do backend, integração com Google Cloud Storage (GCP), otimização do processamento e transferência de arquivos, implementação de internacionalização (i18n) e desenvolvimento de funcionalidades voltadas à escalabilidade e desempenho da plataforma.

  • Migração de Sistema Odontológico Legado

    Migração de um sistema odontológico legado para uma arquitetura moderna baseada em Spring Boot. Atuação na análise e modernização de módulos da aplicação, migração do sistema legado (JSP/Java EE) para uma arquitetura mais moderna, evolução da arquitetura backend, adequação de regras de negócio e apoio ao processo de modernização com auxílio de IA.
